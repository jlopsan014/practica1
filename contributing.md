# Cómo contribuir

Si quieres colaborar en este proyecto, puedes seguir estos pasos:

1. Haz una copia del repositorio.
2. Crea una rama para tus cambios.
3. Modifica los ejercicios o añade nuevas funcionalidades.
4. Comprueba que el código funciona correctamente.
5. Guarda los cambios con un commit.
6. Envía los cambios para su revisión.

## Recomendaciones

- Utiliza nombres claros para las variables.
- Mantén el código ordenado y fácil de entender.
- Comprueba los datos recibidos en los formularios.
- Documenta los nuevos ejercicios en el README.md.

¡Gracias por contribuir!
